# Professional Command-Line Calculator

A modular command-line calculator application built with Python. The project demonstrates clean architecture, error handling, automated testing, and continuous integration.

## Features

- Addition, subtraction, multiplication, and division
- Interactive REPL interface
- Calculation history
- Help and exit commands
- Input validation
- Division-by-zero handling
- LBYL and EAFP error-handling strategies
- Modular application structure
- Unit and parameterized testing
- 100% test coverage
